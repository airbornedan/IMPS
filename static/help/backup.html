Backing Up Your Data

As with all software, it is important to keep IMPS backed up regularly.

Backing up photos

IMPS can create an archive of all the image files in the item image directory. When you installed or configured IMPS, you set the path to the image storage directory. All image files in this directory can be archived and downloaded from the control panel.

To back up your item photos:

  1. From the IMPS home page, click the Control panel (CP) icon
    ().
  2. Select the Backups tab in the control panel.
  3. Click the Archive photos button.
  4. Once the archive is created, IMPS will show the download page. You can click the Download button to download the archive onto your local computer.

    5. Note: The archive contains all the image files you have stored on IMPS. IMPS automatically keeps the 5 most recent photo archives and deletes older ones (both the file and its entry in the Backups tab) once that limit is exceeded. Each of the up-to-5 kept archives is listed with its own download link directly on the Backups tab, not just the single most recent one. You can find these same files in the directory shown in the Backup directory field on the Server tab on the Control panel.

Backing up the database

IMPS has a built-in ability to create a backup of the database. To start a database backup:

  1. From the IMPS home page, click the Control Panel (CP) icon
    ()
  2. Click Backup now to create a backup.
  3. Once the data backup file has been created, IMPS will show the download page. You can click the Download button to download the backup file to your local computer.

    4. Note: The backup contains all the necessary SQL to re-create your database. IMPS automatically keeps the 5 most recent database backups and deletes older ones (both the file and its entry in the Backups tab) once that limit is exceeded. Each of the up-to-5 kept backups is listed with its own download link directly on the Backups tab, not just the single most recent one. You can find these same files in the directory shown in the Backup directory field on the Server tab on the Control panel.
