Backing Up Your Data

As with all software, it is important to keep IMPS backed up regularly.

To back up your database and item photos:

  1. From the IMPS home page, click the Control panel (CP) icon.
  2. Select the Backups tab in the control panel.
  3. Click Backup now.
  4. IMPS redirects back to this tab once the backup is created, where it now appears at the top of the list. Click its download icon to download the database and photos together as a single zip file.

Note: Each backup contains all your item photos plus all the SQL needed to re-create your database, kept separately on the server and zipped together only when you download. IMPS automatically keeps the 4 most recent backups and deletes older ones (both files and their entry on the Backups tab) once that limit is exceeded. Each kept backup is listed with its own download link directly on the Backups tab, not just the most recent one. You can find these same files in the directory shown in the Backup directory field on the Server tab on the Control panel.
