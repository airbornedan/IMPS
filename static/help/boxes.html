Managing Boxes

IMPS uses the concept of boxes as containers for items. You must create a box before adding an item. Each box is assigned a number. IMPS will suggest the next available number sequentially or allow you to choose an unused number. Boxes may also be assigned a name and location, both of which are optional.

Adding a box

  1. From the home page, select Add box to begin adding a new box.
  2. IMPS will show the number of the first unused box (sequentially).
    • You may use this box number by selecting First available unused box number.
    • You may choose a different box number by selecting Choose number and entering a number. Box numbers must be positive integers.
  3. Enter a Location. You may select a location from the dropdown, type a new location name, or choose not to enter a location. If you do not choose a location, the box location will be automatically set to Unspecified.
  4. Enter a Box name. Box names are optional, but are printed on box labels and can help when searching for items.
  5. Click Add box when done to add the box to the database.

Viewing Boxes

  1. From the home page, select Box list to show the list of all boxes or By loc to select a location to show a list of boxes in a specific location.
  2. From the box list page, you can see information about the boxes currently in the IMPS database. On this page you can:
    • Click the items icon to see a list of all items in that box.
    • Click the edit icon to edit the box info.
    • Click the delete icon to delete the box.
    • Click the QR code icon to print the box label.

Edit a box

There's no Edit box tile on the home page -- edit a box from the box list instead.

  1. From the box list page, click the edit icon in that box's row to open its edit form.
  2. Enter a location. You may select a location from the dropdown or type a new location name. You may also delete the current location before submitting the changes. If you do remove the current location, the box location will be automatically set to Unspecified.
  3. Enter a Box name. Box names are optional, but are printed on box labels and can help when searching for items.
  4. Click Update when done to change the box info in the database.
  5. To change the box's number instead, select Change # near the top of the page. This is a separate step from editing the location/name because it also moves every item currently in the box to the new number, and it does not update anything printed on a label you may have already attached to the box -- you'll need to print a new label afterward if you had one.

Delete a box

There's no Del box tile on the home page either -- delete a box from the box list, the same way as editing one.

  1. From the box list page, click the delete icon in that box's row. This opens the Delete a box page with that box number already filled in.
  2. If the box currently has items in it, choose what should happen to them:
    1. Delete the box only, leave the items (they become orphaned)
    2. Delete the box and move all its items to another box
    3. Delete the box and delete all items assigned to it
    (If the box is already empty, this choice is skipped automatically -- there's nothing to orphan, move, or delete.)
  3. Click Next (or Delete box, if the box was empty) to continue to a confirmation page matching your choice.
