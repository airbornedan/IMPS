Adding a box

Use this page to create a new box. Every item in IMPS must live in a box, so at least one box needs to exist before you can add items.

  • Box number – IMPS suggests the next unused number automatically, or you can choose a specific unused number yourself. Box numbers must be positive integers.
  • Location – optional. Pick an existing location from the dropdown or type a new one. If left blank, the box is assigned to Unspecified.
  • Box name – optional. Printed on box labels and shown in box lists to help you identify the box at a glance.

Select Add box to save it.
