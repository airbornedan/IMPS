Edit box

Use this page to change a box's location or name.

  • Location – optional. Pick an existing location from the dropdown or type a new one. Limited to 255 characters.
  • Box name – optional. Printed on box labels and shown in box lists. Limited to 64 characters.

Select Update to save your changes, or Show contents to see the items currently in this box.

To change the box's number itself, use Change # near the top of the page instead — that's a separate step, since it also moves every item in the box to the new number.
