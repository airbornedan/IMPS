Box label

This is a printable label for a box, showing the box number, name (if set), and a QR code.

Scanning the QR code with a phone opens this box's contents page directly — useful for quickly checking what's inside a physical box without typing the number in by hand.

The QR code is generated using the server's configured IP address, so it will only resolve correctly if IMPS is reachable at that address from the device scanning the label.
