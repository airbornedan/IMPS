Renumbering a box

Use this page to change the number assigned to an existing box.

Enter the new box number you'd like to use. IMPS will check that the new number isn't already in use by another box before making the change. All items currently assigned to this box keep their contents and simply move under the new box number.

Renumbering a box changes the URL that any printed QR code label () points to, so existing labels for this box should be reprinted afterward.
