Box contents

This page shows every item currently assigned to one box, along with the box's name and location if set.

From here you can select Add item to add one directly into this box, or select an existing item to view, edit, or delete it. This is also the page that a printed box label's QR code links to. Select a column heading (Item, Date, or Category) to sort by it; select again to reverse. Ctrl/Cmd-click a box number, category, or the delete icon to select several items and move, recategorize, or delete them together.
