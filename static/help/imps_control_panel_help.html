Control Panel: Settings

The Control Panel is the administrative hub for IMPS, split across four pages reachable from the tab bar at the top: Settings, Backups, Cleanup, and Server.

This Settings tab links to the tools for managing the building blocks of your inventory:

  • Categories – add, rename, or delete item categories.
  • Locations – add, rename, or delete box locations.
  • Views – choose which columns appear in item lists and how many items are shown per page.
  • Password – change the shared IMPS login password.
