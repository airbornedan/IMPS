Control Panel

The Control Panel is the administrative hub for IMPS, organized into tabs:

  • Box/Item – manage categories and locations.
  • Backups – back up the database and archive item photos.
  • Cleanup – find and resolve orphaned items and unlinked photo files.
  • Server – view server/database configuration, change the display columns used throughout IMPS, and change the login password.

Select a tab to switch between these tools; IMPS remembers which tab you last used.
