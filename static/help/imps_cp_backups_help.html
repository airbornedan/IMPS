Control Panel: Backups

This tab creates and stores backups of your IMPS data:

  • Archive Photos – zips up all item photos into a single downloadable archive.
  • Backup Now – runs a full database backup and makes it available to download.

Each backup type keeps a short history of recent backups, newest first, so you can download an earlier one if needed — older backups are automatically pruned once the history limit is reached.

Backups are written to the backup directory configured on the Server tab. Downloading a backup file does not remove it from the server.
