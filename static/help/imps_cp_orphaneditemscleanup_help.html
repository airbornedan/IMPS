Orphaned items

This page lists orphaned items — items whose assigned box number no longer exists (usually because the box was deleted while items were left behind rather than moved).

For each orphaned item you can move it into a valid box, or delete it. An option to clear all orphaned items at once is also available. Select a column heading (Item, Date, or Category) to sort by it; select again to reverse.

Ctrl/Cmd-click a box number, category, or the delete icon to select several items and move, recategorize, or delete them together.
