Unlinked photo cleanup

This page lists image files found in the item photo storage directory that are not currently linked to any item in the database — typically left behind after an item was deleted or its photo was replaced.

You can review each unlinked file and delete it individually, or use the option to delete all of them at once (), to reclaim disk space.

Deleting a photo file here only removes the orphaned image on disk; it does not affect any item currently in your inventory.
