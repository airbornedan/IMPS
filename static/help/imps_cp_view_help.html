View settings

This page controls which columns appear in item lists throughout IMPS (inventory, category views, search results, and box contents), along with how many items are shown per page.

  • Information mouseover column – the small info icon that shows an item's full name and description on hover/tap.
  • Photo thumbnail, Added, Category, and Box number columns can each be shown or hidden.
  • Items per page – how many items are shown before list views paginate.

The preview at the top of the page updates live as you change these settings. Settings are saved in your browser and apply across all of IMPS's list views.
