IMPS home page

The IMPS home page is the starting point for everything in the app. Each icon links to a different tool:

  • Search / All items / By category / By box – find items: by name, the full inventory list, grouped by category, or grouped by box.
  • Add item – create a new item.
  • Add box / Box list / By loc – create a new box, see every box, or browse boxes grouped by location.
  • CP – open the Control Panel for administrative tasks (categories, locations, backups, cleanup, and settings).
