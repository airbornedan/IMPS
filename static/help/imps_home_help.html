IMPS home page

The IMPS home page is the starting point for everything in the app. Each icon links to a different tool:

  • Search – find an item by name.
  • All items – the full inventory list.
  • By category / By box / By loc – browse items or boxes grouped by category, box number, or location.
  • Add item / Add box – create a new item or box.
  • Box list – see every box.
  • CP – open the Control Panel for administrative tasks (categories, locations, backups, cleanup, and settings).
