Adding an item

Use this page to add a new item to the inventory. Items must be placed into a box, so at least one box must already exist.

  • Item name – required.
  • Category – optional. Pick an existing category or type a new one; new categories are added to the list automatically. If left blank, the item is set to Uncategorized.
  • Box number – required. IMPS checks that the box number you enter actually exists.
  • Description and photo – optional, but helpful for identifying the item later.

Select the save/add button to add the item to inventory.
