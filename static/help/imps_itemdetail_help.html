Item details

This page shows the full details of a single item: its name, box number, date added, category, description, and photos (if any). On mobile, tapping an item in a list opens this page rather than editing directly — select Edit below to make changes.

From here you can select Edit to change the item, Add another to add a new item to the same box, or Back to return to wherever you came from (falls back to Home if there's nowhere to go back to). Note: there's no delete option on this page — to delete an item, use the trash icon from a list view instead (see the Inventory or Box contents help topics).
