Item details

This page shows the full details of a single item: its name, box number, date added, category, description, and photo (if any).

From here you can select Edit to change the item, Add another to add a new item to the same box, or Home to navigate back to wherever you came from (its box, a category view, or search results). Note: there's no delete option on this page — to delete an item, use the trash icon from a list view instead (see the Inventory or Box contents help topics).
