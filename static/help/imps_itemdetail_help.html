Item details

This page shows the full details of a single item: its name, box number, date added, category, description, and photos (if any).

From here you can select Edit to change the item, or Back to return to wherever you came from (falls back to Home if there's nowhere to go back to). Note: there's no delete option on this page — to delete an item, use the trash icon from a list view instead (see the Inventory or Box contents help topics).
