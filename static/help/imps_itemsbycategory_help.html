Items in a category

This page lists every item assigned to one category, reached by selecting that category on the By category page.

Select a column heading (Item, Date, Category, or Box) to sort by it; select again to reverse. Use the pagination controls if the category has more items than fit on one page. Select an item to view its full details, or Ctrl/Cmd-click a box number, category, or the delete icon to select several items and move, recategorize, or delete them together.
