Deleting multiple items

This is a confirmation page listing every item you selected for deletion — name, category, and box — so you can double-check before anything is removed.

Use each row's Don't delete to take just that item off the list. Removing the last item on the list returns you to where you started, with nothing deleted.

Deleting an item also removes its associated photo file, if it has one. Select All to confirm deleting everything still listed — this cannot be undone. Back returns you to where you started without deleting anything.
