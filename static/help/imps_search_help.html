Search

Enter a search term and select Search to find matching items. IMPS checks your search term, word by word, against each item's name, description, and category, so a match doesn't have to be in the name alone. It also does a phonetic ("sounds like") match against item names, so a typo such as "lampp" can still find "lamp."

Leaving the search box empty and searching takes you to the full inventory (All items) instead.
