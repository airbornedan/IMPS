Search

Enter a search term and select Search (or press Enter) to find matching items. IMPS checks your search term, word by word, against each item's name, description, category, and location, so a match doesn't have to be in the name alone — searching "garage" finds everything stored there, and "Christmas" finds everything in that category. A whole number also matches a box number directly, so searching "9" finds everything in box 9. It also does a phonetic ("sounds like") match against item, category, and location names, so a typo such as "lampp" or "Decrating" can still find "lamp" or "Decorating."

Leaving the search box empty and searching takes you to the full inventory ( All items) instead.
