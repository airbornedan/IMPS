Using QR code labels

About QR codes

When you create and print a box label, the label will contain a QR code image that will be a link to the IMPS box contents page for that box. Box labels are accessible from most box view pages by clicking the Label button. This QR code is generated by IMPS based on your IMPS server's IP address (the imps_ip setting in imps_config.toml). This means that your IMPS server must have a static IP address in order for the label QR code to work correctly.

The QR code always links to a plain http:// address with no port number included, so it assumes IMPS is being served on the standard HTTP port (80). This is the case for the WSGI/Apache deployment described in the install instructions.

If you print labels while testing IMPS with Flask's built-in development server (which serves pages on its own port, not port 80), the QR codes will not work correctly, since the label always points to port 80 regardless of what port Flask is actually using. Wait until IMPS is running under its normal WSGI/Apache setup before printing labels you intend to keep using.
