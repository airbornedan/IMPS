Troubleshooting IMPS

Installation issues

Pip issues

If you attempt to install IMPS using the directions provided and you encounter dependency errors running pip install -r requirements.txt you can attempt to resolve these by installing the libraries individually. For example, if the above command fails with a version error for the bcrypt library, you can try pip install bcrypt to install it.

Database issues

The first time IMPS is opened in a browser, it will take you to the /setup wizard, which tests your database connection live and shows you the result on the spot -- see Notes on setting up the database for the full walkthrough. Once setup is complete, IMPS instead opens a welcome page that shows you the status of various settings. If the database setting section has red indicators, or pages consistently return database errors, it's likely your database connection is misconfigured. To manually check your database, start your db server's interactive environment (mysql -u root) and verify that your server is running and reachable. Then, attempt to login using the credentials you set in imps_config.toml ( mysql -u <user> -p <password>)

Included with IMPS in the static/backup directory are a setup.sql file (creates the database and database user) and a schema.sql file (creates IMPS's tables). Check that this structure exists.

Directory issues

If you encounter problems with IMPS related to reading or writing files, check that the correct directories are set in imps_config.toml and that they are read/writable by whichever user account is running IMPS.

Password problems

If you cannot access IMPS because of problems with your password, view what it is set to in imps_config.toml and verify that you are using the same password to log in. There is no way to change the password from within the running app -- either edit the password value in imps_config.toml directly and restart IMPS, or re-run the setup wizard's password step by creating an empty file named first.run in your IMPS directory and visiting /setup again.
