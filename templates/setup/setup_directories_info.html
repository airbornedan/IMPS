Directory settings

Unlike the database connection and IMPS password, these settings aren't configurable from this wizard -- getting imps_dir wrong is exactly what stops IMPS from starting at all (see app/extensions.py), so they need to be set directly in imps_config.toml before IMPS is even running, rather than through a page IMPS itself serves.

The file is in the same directory where you installed IMPS, most likely /var/www/ if you're using Apache on Ubuntu. Open it in a text editor and check the [directories] section:

  • imps_ip -- the IP address of the server running IMPS.
  • imps_dir -- the absolute path to the directory IMPS is installed in (e.g. /var/www/). If this is wrong, IMPS won't start at all -- you'll see this in a terminal, not in the browser.
  • item_image_dir -- path (relative to imps_dir) where IMPS stores item images. The default is /static/images/items/ -- keep the leading slash; it's used directly in image URLs, not just as a filesystem path. You may use any directory IMPS has read/write access to; to use one outside IMPS's own folder, create a symlink rather than changing this to an unrelated absolute path.
  • backup_dir -- path (relative to imps_dir) where IMPS stores database and photo backups made from the control panel. The default is static/backup.

After editing imps_config.toml, restart IMPS (a plain config file edit isn't picked up live the way database settings and the IMPS password are through this wizard) and come back here to confirm the lights above are green.
