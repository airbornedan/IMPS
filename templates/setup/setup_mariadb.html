Install MariaDB (Ubuntu)

These steps assume Ubuntu, since that's the only OS IMPS officially supports. Run each block below in a terminal on the server IMPS is installed on.

1. Install the MariaDB server

sudo apt update
sudo apt install mariadb-server

2. (Recommended) Run the included security script

Sets a root password, removes anonymous users, and disables remote root login. Answer "Y" to each prompt unless you have a specific reason not to.

sudo mysql_secure_installation

3. Create the IMPS database and user

This creates a dedicated box_db database and box_user account scoped to it -- IMPS never needs (and shouldn't have) a root database connection. Feel free to change the username/password below, as long as you use the same values on the next page.

sudo mysql -u root < static/backup/setup.sql

(Run that from the directory IMPS is installed in, or adjust the path to setup.sql accordingly.)

That's it for the command line. Once this is done, come back here and enter the database name/user/password you just created.
